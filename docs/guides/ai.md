# AI 使用说明

## 1. 接入 AI 服务

打开 **设置 → AI 服务**。左边是服务商列表，右边是所选服务商的配置，用法和 Cherry Studio 一样。

### 方式一：用 Claude Code / Codex 订阅（不需要 API Key）

如果你订阅了 Claude（Pro / Max）或 ChatGPT（Plus / Pro），可以直接用订阅额度。

1. **安装并登录命令行工具**（只需一次）：
   ```bash
   # Claude Code
   npm install -g @anthropic-ai/claude-code   # 或按官网用安装脚本
   claude                                     # 第一次运行时按提示登录你的 Claude 账号

   # Codex
   npm install -g @openai/codex               # 或 brew install codex
   codex login                                # 选择用 ChatGPT 账号登录
   ```
2. **在 Mailbox AI 里启用**：在 设置 → AI 服务 中选「Claude Code」或「Codex」。
   - 能看到「已找到 …/claude（版本号）」就说明可用。
   - 找不到时，在「自定义路径」里填写完整路径，可以在终端里用 `which claude` 查看。
3. **选择模型**：
   - `default`：使用命令行工具自己的默认模型。
   - Claude Code 也可以选 `sonnet`、`opus`、`haiku`。
4. 点「检查连接」测试是否可用。

**说明**：
- 邮件内容只通过本机的命令行工具发送。工作目录是一个空文件夹，所有读写文件和执行命令的工具都已禁用。
- 命令行工具每次调用都要启动一个进程，所以比直接调 API 慢几秒，更适合写信、总结这类不着急的任务。

### 方式二：填写 API Key

1. **找到服务商**：在列表里找到你的服务商，比如 DeepSeek、通义千问、Kimi、智谱、硅基流动、OpenAI、Anthropic 或 Gemini。
2. **填写 API Key**：点「获取密钥」会打开该服务商的控制台。
3. **一般不用改 API 地址**。用中转或代理时，改成对应地址即可。
4. **添加模型**：点「拉取模型」从服务商获取模型列表，勾选要用的；也可以手动添加模型 id。
5. 点「检查连接」测试是否可用。

**自定义服务商**：点列表底部的「添加自定义服务商」，类型选「OpenAI 兼容」，然后填写 API 地址和 Key。大部分国内外中转服务都兼容这种方式。

### 方式三：本地模型（邮件完全不出本机）

- **Ollama**：
  1. 安装 Ollama 后，在终端执行 `ollama pull qwen2.5:7b`（或其他模型）。
  2. 在「Ollama」里点「拉取模型」并勾选。
- **LM Studio**：在 LM Studio 中打开 Local Server，然后在「LM Studio」里拉取模型。

## 2. 选择模型

在 **设置 → AI 功能** 中选择两类模型：

- **默认模型**：用于写信、回复、对话和问问邮箱。建议选效果好的模型。
- **快速模型**：用于摘要、翻译、分类、智能提醒和 Loop。建议选便宜、快的模型，比如 DeepSeek、通义 Turbo、Haiku 或本地模型。

只设置其中一个也可以，另一个会自动使用同一个模型。

同一页还可以设置：
- AI 输出语言。
- 写作语气。
- 落款称呼。
- 是否允许处理加密邮件（默认不允许）。

## 3. 写信

写信窗口底部有「✨ AI」菜单。

- **改写**：润色、更正式、更友好、更简洁、扩写、纠错、翻译成英文或中文。
  - 先选中一段文字，就只改写这一段；不选就改写整封正文。签名和引用的原文不会被改动。
- **帮我写…**：输入一句要求，比如「向王经理申请下周三请假一天」，AI 会生成整封邮件。如果主题栏是空的，会自动填上主题。
- **自定义指令…**：例如「改成适合发给客户的语气，并列出三点」。

结果会先显示在侧边面板里。你可以选择：**替换**、**插入到下方**、**重新生成**或**放弃**。

**一键回复**：回复邮件时，正文上方有一行输入框。比如输入「同意，下周二可以，地点在 3 楼会议室」，然后按回车，就会生成完整的回复。

## 4. 阅读：代读、翻译、建议回复

阅读区工具栏的 ✨ 菜单中有：

- **总结这封邮件 / 总结整个会话**：在邮件上方的 AI 卡片里显示「一句话结论 + 要点 + 待办」。结果会缓存，下次打开直接显示。
- **朗读摘要 / 朗读全文**：用系统语音朗读。在 设置 → AI 功能 中可以选择语音和语速；中文语音排在前面。
- **翻译成中文 / 英文**
- **建议回复**：正文下方会出现 3 个回复建议，点一下就打开写好的回复窗口。
- **分析待办**：识别这封邮件是否需要回复、截止时间和待办事项。

在 设置 → AI 功能 中开启「打开长邮件时自动总结」后，打开长邮件会自动显示摘要。

## 5. 智能提醒与「✨ 待处理」

开启后（设置 → AI 功能 → 智能提醒），每封新邮件到达时，AI 会在后台判断：

- 是否需要你回复
- 有没有截止时间（会把「周五前」这类说法换算成具体日期）
- 有哪些待办

结果汇总在侧边栏的 **✨ 待处理** 中。到达提醒时间时，会弹出这样的通知：「⏰ [QQ·工作] 王经理 · 截止 周五前」。

- 提醒时间：截止前一天上午 9 点；如果离截止不到一天，就是截止前 2 小时。
- 回复了这封邮件后，它会自动从「需要回复」中移除。
- 分析范围可以选「仅主要分类」（默认）、「全部」或「仅 VIP」，以控制费用。

## 6. 批量处理

在邮件列表中多选邮件（⌘ 或 ⇧ 点击），然后右键选择 **✨ AI 批量处理…**。可以做这些事：

| 操作 | 结果 |
|---|---|
| 总结 | 每封一句话，最后给出整体汇总 |
| 分类整理 | 给出标签、分类、归档或删除的建议；勾选后点「应用所选」才会执行 |
| 提取待办 | 列出所有待办 |
| 生成回复草稿 | 为每封生成回复，保存在「草稿」中 |
| 自定义指令 | 比如「提取每封邮件里的订单号和金额」 |

## 7. Loop（定时 AI 任务）

在 设置 → AI 功能 → Loop 中新建。可以直接从模板开始：

- **每日早报**：每天 8:00 总结过去 24 小时的未读邮件，列出今天要处理的事。
- **待回复检查**：工作日 17:30 找出还没回复的邮件，并给出回复要点。
- **每周账单汇总**：每周一汇总上周的账单和发票。
- **订阅清理建议**：每周日统计营销邮件，建议哪些可以退订。

每个 Loop 可以设置：
- **频率**：每天、工作日、每周或每隔 N 分钟。
- **搜索条件**：和搜索框的语法相同，例如 `is:unread newer_than:1d`。
- **处理指令**
- **完成后的动作**：发通知，或把结果作为一封邮件投递到收件箱。

运行结果可以在 Loop 列表或 **✨ AI 助手 → Loop** 中查看，也可以随时「立即运行」。

## 8. 自动回复

在 设置 → AI 功能 → 自动回复 中添加规则：

- **匹配条件**：
  - 按发件人或主题关键字匹配。
  - 也可以用一句话描述，例如「询问产品价格的客户邮件」，由 AI 判断。
- **回复要求**：例如「礼貌地告知报价单会在 1 个工作日内发送，并询问需求数量」。
- **方式**：
  - **生成草稿**（默认，推荐）：生成回复草稿并通知你，确认后再手动发送。
  - **直接发送**：开启时需要二次确认。发出的邮件带有 `Auto-Submitted` 信头，避免和对方的自动回复互相循环。
- **限制**：
  - 每条规则每天的上限。
  - 同一发件人多少小时内只回复一次。
  - noreply 地址、群发邮件和对方发来的自动回复一律跳过。

## 9. 问问邮箱

点侧边栏的 **✨ AI 助手**，然后直接提问：

- 「上个月京东的账单一共多少钱？」
- 「李四说的接口文档更新了什么？」
- 「下周有哪些会议邀请？」

AI 会先在本地搜索相关邮件，再根据邮件内容回答。回答中的 [1]、[2] 是引用编号，点击可以打开对应的邮件。

在阅读区的 ✨ 菜单中选「问问 AI」，可以针对当前这封邮件提问。

## 10. 隐私与费用

- API Key 加密保存在本机的 secrets 文件中，主密钥放在钥匙串里。
- 只有你主动使用 AI 功能，或开启了智能提醒、自动回复、Loop 时，才会把相关邮件发给所选的 AI 服务。
- 每次发送的正文有长度上限，默认 12000 字，可以在设置中调整。
- 加密邮件默认不交给 AI。
- 想完全不把邮件发到外部，请使用 Ollama 或 LM Studio 本地模型。
