# AI 使用说明

## 1. 接入 AI 服务

打开 **设置 → AI 服务**。左边是服务商列表，右边是所选服务商的配置，用法和 Cherry Studio 一样。

### 方式一：用 Claude Code / Codex 订阅（不需要 API Key）

如果你订阅了 Claude（Pro / Max）或 ChatGPT（Plus / Pro），可以直接用订阅额度。

1. **安装并登录命令行工具**（只需一次）：
   ```bash
   # Claude Code
   npm install -g @anthropic-ai/claude-code   # 或按官网用安装脚本
   claude                                     # 第一次运行时按提示登录你的 Claude 账号

   # Codex
   npm install -g @openai/codex               # 或 brew install codex
   codex login                                # 选择用 ChatGPT 账号登录
   ```
2. **在 Mailbox AI 里启用**：在 设置 → AI 服务 中选「Claude Code」或「Codex」。
   - 能看到「已找到 …/claude（版本号）」就说明可用。
   - 找不到时，在「自定义路径」里填写完整路径，可以在终端里用 `which claude` 查看。
3. **选择模型**：
   - `default`：使用命令行工具自己的默认模型。
   - Claude Code 也可以选 `sonnet`、`opus`、`haiku`。
4. 点「检查连接」测试是否可用。

**说明**：
- 邮件内容只通过本机的命令行工具发送。工作目录是一个空文件夹，所有读写文件和执行命令的工具都已禁用。
- 命令行工具每次调用都要启动一个进程，所以比直接调 API 慢几秒，更适合写信、总结这类不着急的任务。

### 方式二：填写 API Key

1. **找到服务商**：在列表里找到你的服务商，比如 DeepSeek、通义千问、Kimi、智谱、硅基流动、OpenAI、Anthropic 或 Gemini。
2. **填写 API Key**：点「获取密钥」会打开该服务商的控制台。
3. **一般不用改 API 地址**。用中转或代理时，改成对应地址即可。
4. **添加模型**：点「拉取模型」从服务商获取模型列表，勾选要用的；也可以手动添加模型 id。
5. 点「检查连接」测试是否可用。

**多个 API Key**：Key 栏可以填多个，用英文逗号或换行分隔。每次请求会轮流使用；某个 Key 失效或限流（401 / 429）时，会自动换下一个重试。

**模型能力**：模型列表中，每个模型会显示能力标签（看图、推理、工具、嵌入）。这些标签是按模型名自动判断的，判断不准时可以手动开关。

**自定义服务商**：点列表底部的「添加自定义服务商」，类型选「OpenAI 兼容」，然后填写 API 地址和 Key。大部分国内外中转服务都兼容这种方式。

### 方式三：本地模型（邮件完全不出本机）

- **Ollama**：
  1. 安装 Ollama 后，在终端执行 `ollama pull qwen2.5:7b`（或其他模型）。
  2. 在「Ollama」里点「拉取模型」并勾选。
- **LM Studio**：在 LM Studio 中打开 Local Server，然后在「LM Studio」里拉取模型。
- **Apple 端侧模型**：
  - 需要 macOS 26 和支持 Apple Intelligence 的 Mac，并在 系统设置 → Apple Intelligence 与 Siri 中打开 Apple Intelligence。
  - 在「Apple 端侧模型」里打开开关即可，页面上会显示是否可用。
  - 模型由 Mailbox AI 助手在本机提供（127.0.0.1:47922），免费且不联网。
  - 上下文较短，适合摘要、分类和短邮件改写；长邮件会被截断。

## 2. 选择模型

在 **设置 → AI 功能** 中选择两类模型：

- **默认模型**：用于写信、回复、对话和问问邮箱。建议选效果好的模型。
- **快速模型**：用于摘要、翻译、分类、智能提醒和 Loop。建议选便宜、快的模型，比如 DeepSeek、通义 Turbo、Haiku 或本地模型。

只设置其中一个也可以，另一个会自动使用同一个模型。

此外还可以设置两个专用模型，都是可选的：
- **看图模型**：用于解读图片附件。不设置时，如果默认模型支持看图，就用默认模型。
- **向量嵌入模型**：用于「问问邮箱」的语义排序，能让回答找到更相关的邮件。支持 OpenAI 兼容接口和 Gemini。

同一页还可以设置：
- AI 输出语言。
- 写作语气。
- 落款称呼。
- 是否允许处理加密邮件（默认不允许）。

## 3. 写信

写信窗口底部有「✨ AI」菜单。

- **改写**：润色、更正式、更友好、更简洁、扩写、纠错、翻译成英文或中文。
  - 先选中一段文字，就只改写这一段；不选就改写整封正文。签名和引用的原文不会被改动。
- **帮我写…**：输入一句要求，比如「向王经理申请下周三请假一天」，AI 会生成整封邮件。如果主题栏是空的，会自动填上主题。
- **自定义指令…**：例如「改成适合发给客户的语气，并列出三点」。

结果会先显示在侧边面板里。你可以选择：**替换**、**插入到下方**、**重新生成**或**放弃**。

**生成主题**：✨ 菜单中的「生成主题」会根据正文写一行主题；如果主题栏已经有内容，会先问你是否覆盖。

**我的提示词**：✨ 菜单中的「我的提示词」列出你在提示词库里保存的写信类提示词（见第 13 节）。

**一键回复**：回复邮件时，正文上方有一行输入框。比如输入「同意，下周二可以，地点在 3 楼会议室」，然后按回车，就会生成完整的回复。

## 4. 阅读：代读、翻译、建议回复

阅读区工具栏的 ✨ 菜单中有：

- **总结这封邮件 / 总结整个会话**：在邮件上方的 AI 卡片里显示「一句话结论 + 要点 + 待办」。结果会缓存，下次打开直接显示。
- **朗读摘要 / 朗读全文**：用系统语音朗读。在 设置 → AI 功能 中可以选择语音和语速；中文语音排在前面。
- **翻译成中文 / 英文**
- **建议回复**：正文下方会出现 3 个回复建议，点一下就打开写好的回复窗口。
- **分析待办**：识别这封邮件是否需要回复、截止时间和待办事项。

在 设置 → AI 功能 中开启「打开长邮件时自动总结」后，打开长邮件会自动显示摘要。

**提取日程到日历**：✨ 菜单中的「提取日程到日历」会找出邮件里提到的会议和活动，并把「下周二下午 3 点」这类说法换算成具体时间。在列表里改好标题和时间后，点「加入日历」即可。智能分析找到日程时，邮件头部会显示「📅 日程 N」标签，点一下也能打开同一个列表。

**解读附件**：在附件上右键（或在 ✨ 菜单中）选「AI 解读附件」：
- **PDF**：先在本机用系统的 PDFKit 提取文字，再交给 AI 总结。
- **图片**：需要支持看图的模型，比如截图、扫描件、发票照片。
- **文本、CSV、Markdown、JSON**：直接读取。

**钓鱼和诈骗提示**：AI 判断邮件疑似钓鱼或诈骗（冒充官方、索要密码或验证码、要求转账、可疑链接等）时，阅读区顶部会显示红色提示和理由。

## 5. 智能提醒与「✨ 待处理」

开启后（设置 → AI 功能 → 智能提醒），每封新邮件到达时，AI 会在后台判断：

- 是否需要你回复
- 有没有截止时间（会把「周五前」这类说法换算成具体日期）
- 有哪些待办

结果汇总在侧边栏的 **✨ 待处理** 中。到达提醒时间时，会弹出这样的通知：「⏰ [QQ·工作] 王经理 · 截止 周五前」。

- 提醒时间：截止前一天上午 9 点；如果离截止不到一天，就是截止前 2 小时。
- 回复了这封邮件后，它会自动从「需要回复」中移除。
- 分析范围可以选「仅主要分类」（默认）、「全部」或「仅 VIP」，以控制费用。

**通知方式**（设置 → AI 功能 → 常规）：
- **普通**（默认）：新邮件照常弹出通知。
- **附加 AI 摘要**：分析完成后，把通知正文更新为「✨ 一句话摘要」，不会再响一次。
- **只提醒重要邮件**：先由 AI 判断，只有高优先级、需要回复、VIP、或疑似钓鱼的邮件才弹通知。AI 出错或 90 秒内没有结果时，照常弹出通知，不会漏掉。

**跟进提醒**：你发出的邮件超过 N 天（默认 3 天，可以设为 0 关闭）还没收到回复，并且 AI 判断这封邮件在等对方回复时，会加入「✨ 待处理」，并提醒你「N 天没收到 某某 的回复」。对方回复后，提醒会自动消失。

## 6. 批量处理

在邮件列表中多选邮件（⌘ 或 ⇧ 点击），然后右键选择 **✨ AI 批量处理…**。可以做这些事：

| 操作 | 结果 |
|---|---|
| 总结 | 每封一句话，最后给出整体汇总 |
| 分类整理 | 给出标签、分类、归档或删除的建议；勾选后点「应用所选」才会执行 |
| 提取待办 | 列出所有待办 |
| 生成回复草稿 | 为每封生成回复，保存在「草稿」中 |
| 自定义指令 | 比如「提取每封邮件里的订单号和金额」 |
| 批量退订 | 对带退订链接的邮件逐一退订（不调用 AI）；需要在浏览器里确认的，会列出链接 |

## 7. Loop（定时 AI 任务）

在 设置 → AI 功能 → Loop 中新建。可以直接从模板开始：

- **每日早报**：每天 8:00 总结过去 24 小时的未读邮件，列出今天要处理的事。
- **待回复检查**：工作日 17:30 找出还没回复的邮件，并给出回复要点。
- **每周账单汇总**：每周一汇总上周的账单和发票。
- **订阅清理建议**：每周日统计营销邮件，建议哪些可以退订。

每个 Loop 可以设置：
- **频率**：每天、工作日、每周或每隔 N 分钟。
- **搜索条件**：和搜索框的语法相同，例如 `is:unread newer_than:1d`。
- **处理指令**
- **完成后的动作**：发通知，或把结果作为一封邮件投递到收件箱。

运行结果可以在 Loop 列表或 **✨ AI 助手 → Loop** 中查看，也可以随时「立即运行」。

## 8. 自动回复

在 设置 → AI 功能 → 自动回复 中添加规则：

- **匹配条件**：
  - 按发件人或主题关键字匹配。
  - 也可以用一句话描述，例如「询问产品价格的客户邮件」，由 AI 判断。
- **回复要求**：例如「礼貌地告知报价单会在 1 个工作日内发送，并询问需求数量」。
- **方式**：
  - **生成草稿**（默认，推荐）：生成回复草稿并通知你，确认后再手动发送。
  - **直接发送**：开启时需要二次确认。发出的邮件带有 `Auto-Submitted` 信头，避免和对方的自动回复互相循环。
- **休假回复**：在规则编辑器顶部切换到「休假回复」，填写回复内容和起止日期。休假回复不调用 AI，在这段时间内会直接发送，同一个人只会收到一次。
- **限制**：
  - 每条规则每天的上限。
  - 同一发件人多少小时内只回复一次。
  - noreply 地址、群发邮件和对方发来的自动回复一律跳过。

## 9. 问问邮箱

点侧边栏的 **✨ AI 助手**，然后直接提问：

- 「上个月京东的账单一共多少钱？」
- 「李四说的接口文档更新了什么？」
- 「下周有哪些会议邀请？」

AI 会先在本地搜索相关邮件，再根据邮件内容回答。回答中的 [1]、[2] 是引用编号，点击可以打开对应的邮件。

在阅读区的 ✨ 菜单中选「问问 AI」，可以针对当前这封邮件提问。

打开输入框旁的「🔧 使用工具」后，AI 还可以调用你接入的外部 MCP 工具，比如查询日历、读取网页或公司内部系统（见第 12 节）。回答下方会列出调用过哪些工具。

## 10. 隐私与费用

- API Key 加密保存在本机的 secrets 文件中，主密钥放在钥匙串里。
- 只有你主动使用 AI 功能，或开启了智能提醒、自动回复、Loop 时，才会把相关邮件发给所选的 AI 服务。
- 每次发送的正文有长度上限，默认 12000 字，可以在设置中调整。
- 加密邮件默认不交给 AI。
- 想完全不把邮件发到外部，请使用 Apple 端侧模型、Ollama 或 LM Studio。

## 11. MCP：让 Claude Code / Codex 直接操作邮箱

Mailbox AI 内置一个邮箱 MCP 服务。开启后，Claude Code、Codex、Cherry Studio 等工具可以搜索和阅读邮件、写草稿、标记和归档邮件。**发送和删除**每次都要你在 Mailbox AI 里点「允许」才会执行，3 分钟内没有回应就自动取消。

1. 打开 设置 → AI 功能 → **MCP**，打开「启用 MCP 服务」。
2. 复制页面上对应工具的配置：
   - **Claude Code**（终端执行一次即可）：
     ```bash
     claude mcp add --transport http mailbox-ai http://127.0.0.1:47921/mcp --header "Authorization: Bearer <令牌>"
     ```
   - **Codex**：把页面上的片段加到 `~/.codex/config.toml`。它通过助手 App 的 `--mcp` 模式（stdio）连接。
   - **Cherry Studio** 或其他客户端：类型选 Streamable HTTP，填写 URL 和 `Authorization` 头。
3. 然后就可以直接说，比如「帮我把今天所有未读的通知类邮件标为已读」「给李四回复一下，说接口文档我看过了」。

**可用工具**：

| 类别 | 工具 |
|---|---|
| 账户与搜索 | 列出账户、搜索邮件、列出未读、读取邮件、读取会话、查看待处理 |
| 写信 | 写草稿、写回复草稿、发送邮件（需要确认） |
| 整理 | 标记已读 / 未读、加星 / 取消星标、归档、删除（需要确认） |

**确认方式**：AI 请求发送或删除时，Mailbox AI 会弹出确认窗口，显示收件人、主题和正文开头，或者要删除的邮件列表。即使主窗口没开，也会收到一条带「允许 / 拒绝」按钮的通知。

**安全**：
- MCP 只监听本机 `127.0.0.1`，必须带令牌才能访问。令牌可以随时重新生成，旧令牌立即失效。
- 账户级的 AI 策略（第 14 节）同样作用于 MCP：关闭了 AI 的账户，MCP 也读不到它的邮件正文。

## 12. 外部 MCP 工具

在 设置 → AI 功能 → MCP → **外部工具** 中，可以添加其他 MCP 服务器给 AI 助手用：
- **stdio**：填写命令和参数，例如 `npx -y @modelcontextprotocol/server-filesystem ~/Documents`。
- **HTTP**：填写 URL 和请求头。

点「测试」可以列出这个服务器提供的工具。添加后，在 AI 助手里打开「🔧 使用工具」即可。

各服务商的支持情况：
- **OpenAI 兼容、Anthropic、Gemini**：都支持工具调用。
- **Claude Code**：会把这些 MCP 服务器交给它自己管理。
- **Codex**：暂不支持外部工具。

## 13. 提示词库

在 设置 → AI 功能 → **提示词** 中保存常用指令，分为三类：
- **写信**：出现在写信窗口的「✨ → 我的提示词」，例如「改成适合发给客户的语气」。
- **阅读**：出现在阅读区的「✨ → 我的提示词」，例如「提取所有金额和日期」。结果显示在 AI 卡片中。
- **批量**：在批量处理中可以直接选用，例如「提取订单号和金额，输出表格」。

## 14. 账户级 AI 策略与用量

**每个账户单独设置**（设置 → AI 功能 → 常规）：
- **启用**：默认。
- **关闭**：这个账户的邮件不会交给任何 AI 功能，包括智能分析、自动回复、Loop、问问邮箱和 MCP 读取。
- **仅本地模型**：只允许 Ollama、LM Studio，或者地址指向本机的服务商处理这个账户的邮件。适合公司邮箱等敏感账户。

**用量统计**（设置 → AI 功能 → 用量）：
- 按天显示调用次数和 token 用量，并按模型、按功能汇总，方便估算费用。
- 用订阅 CLI 时，token 能取到就记录，取不到记为 0。
